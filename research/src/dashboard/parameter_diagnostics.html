Rule definitions & comparison method

Timing: signal at day t close → execution at the next available close → first earned daily return ends one further trading day later. Indicators are warmed on earlier prices; all versions use exactly the same displayed dates. Changing dates slices existing continuous accounts, without restarting positions.

Pooled distribution: each valid pair-day has equal weight. On the shared calendar each pair has equal weight. Currency observations are dependent; a larger pooled count is not a count of independent observations. Entry counts are summed across separate accounts.

Drawdown: decline from the running peak of window-reset equity, shown as percentage points of the initial $100,000; peak-equity drawdown is also reported in the trading table. Exposure counts days earning a return with a nonzero held position, including zero-price-change days.
